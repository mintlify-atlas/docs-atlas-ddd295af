Airbyte's connector catalog gives you access to 600+ pre-built connectors for moving data between hundreds of sources and destinations. Whether you need to replicate a production database, pull data from a SaaS API, or load data into a cloud data warehouse, there is a connector available.

## Sources and destinations

**Sources** are systems Airbyte reads data from. A source connector connects to a data origin—a database, API, or file store—and extracts records that Airbyte delivers to your destination.

**Destinations** are systems Airbyte writes data to. A destination connector receives records from one or more sources and loads them into a target storage system such as a data warehouse, database, or object store.

You combine a source and a destination into a **connection**, which defines what data to sync, how often, and in which mode.

## Finding and adding connectors

<Steps>
  <Step title="Open Sources or Destinations">
    In the Airbyte UI, click **Sources** or **Destinations** in the left navigation bar.
  </Step>
  <Step title="Search for a connector">
    Click **+ New source** (or **+ New destination**), then use the search box to filter by name.
  </Step>
  <Step title="Configure the connector">
    Select the connector you want, fill in the required fields, and click **Set up source** or **Set up destination**.
  </Step>
  <Step title="Create a connection">
    After both a source and destination are configured, navigate to **Connections** and click **+ New connection** to link them.
  </Step>
</Steps>

## Building custom connectors

If no existing connector meets your needs, you can build your own using the **Connector Builder**—a no-code interface for creating HTTP API connectors—or by using the Airbyte CDK to write a connector in Python or Java.

<Card title="Connector Builder" icon="wrench" href="https://docs.airbyte.com/connector-development/connector-builder-ui/overview">
  Build a custom API connector without writing code using the visual Connector Builder UI.
</Card>
