## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I use Airbyte commercially?">
    Yes. You can run Airbyte self-hosted for commercial purposes — for example, to power internal data pipelines or customer-facing data products — without restriction.
  </Accordion>
  <Accordion title="Can I offer Airbyte as a managed service?">
    No. The ELv2 license prohibits providing the Airbyte platform to third parties as a hosted or managed service where users can access a substantial portion of its features. This means you cannot build a competing managed Airbyte offering.

    Airbyte Cloud is the official hosted offering. If you need a managed deployment, contact Airbyte about its cloud and enterprise options.
  </Accordion>
  <Accordion title="Can I fork and modify Airbyte?">
    Yes, for internal use or self-managed deployments. You must include prominent notices in any modified copies stating that you have modified the software, and you must preserve all license and copyright notices. The same restrictions on hosting apply to forks.
  </Accordion>
  <Accordion title="Can I use Airbyte connectors freely?">
    Yes. Connectors are MIT-licensed. You can use, modify, and redistribute connector code without restriction, including commercially.
  </Accordion>
  <Accordion title="Does ELv2 affect the Airbyte API or Terraform provider?">
    The API and Terraform provider interact with the Airbyte platform, which is ELv2-licensed. Using the API or Terraform provider to manage your own Airbyte deployment is permitted. What is not permitted is re-packaging the platform itself as a competing hosted service.
  </Accordion>
</AccordionGroup>
