---
title: "Quickstart"
description: "Deploy Airbyte locally and run your first data sync in minutes."
---

This guide walks you from zero to your first successful sync. You will deploy Airbyte on your local machine using `abctl`, connect a source and a destination, and trigger a sync.

<Steps>
  <Step title="Install Docker Desktop">
    abctl requires Docker. Install Docker Desktop for your operating system before proceeding.

    - [Mac](https://docs.docker.com/desktop/install/mac-install/)
    - [Windows](https://docs.docker.com/desktop/install/windows-install/)
    - [Linux](https://docs.docker.com/desktop/install/linux-install/)

    Start Docker Desktop and make sure it is running before continuing.
  </Step>

  <Step title="Install abctl">
    abctl is Airbyte's command-line installer. It creates a local Kubernetes cluster inside Docker and installs Airbyte using Helm—no Kubernetes knowledge required.

    <Tabs>
      <Tab title="curl">
        ```shell
        curl -LsfS https://get.airbyte.com | bash -
        ```

        Enter your password if prompted. When installation completes, you see `abctl install succeeded`.
      </Tab>
      <Tab title="Homebrew">
        ```bash
        brew tap airbytehq/tap
        brew install abctl
        ```
      </Tab>
      <Tab title="Go">
        ```bash
        go install github.com/airbytehq/abctl@latest
        ```
      </Tab>
    </Tabs>

    Verify the installation:

    ```bash
    abctl version
    ```
  </Step>

  <Step title="Deploy Airbyte">
    Run the following command to install Airbyte locally. Depending on your internet speed, this may take up to 30 minutes.

    ```bash
    abctl local install
    ```

    When the command finishes, Airbyte is running and accessible at `http://localhost:8000`.

    <Note>
      abctl automatically opens your browser when the installation completes. You can disable this with the `--no-browser` flag.
    </Note>
  </Step>

  <Step title="Open the Airbyte UI and log in">
    Navigate to `http://localhost:8000` in your browser.

    To find your login credentials, run:

    ```bash
    abctl local credentials
    ```

    The command returns your email, password, client ID, and client secret. Use the email and password to log in.
  </Step>

  <Step title="Add a source">
    A source is the system you want to pull data from.

    1. In the Airbyte UI, click **Sources** in the left navigation.
    2. Click **New source**.
    3. Search for and select a connector—for example, **Sample Data (Faker)** is a built-in source that requires no credentials and is useful for testing.
    4. Fill in the required fields and click **Set up source**.

    Airbyte tests the connection. When the test passes, your source is ready.
  </Step>

  <Step title="Add a destination">
    A destination is the system where Airbyte writes data.

    1. Click **Destinations** in the left navigation.
    2. Click **New destination**.
    3. Search for and select a connector—for example, **Local JSON** writes data to your local filesystem with no extra setup.
    4. Fill in the required fields and click **Set up destination**.

    Airbyte tests the connection. When the test passes, your destination is ready.
  </Step>

  <Step title="Create a connection">
    A connection links a source to a destination and defines how data moves between them.

    1. Click **Connections** in the left navigation.
    2. Click **New connection**.
    3. Select the source you just created.
    4. Select the destination you just created.
    5. Review the streams you want to sync and select a sync mode.
    6. Configure the connection name, schedule, and destination namespace as needed.
    7. Click **Set up connection**.
  </Step>

  <Step title="Run your first sync">
    On the connection page, click **Sync now** to trigger an immediate sync.

    The **Status** tab shows the sync progress. When the sync completes, you will see a summary of the records synced. You can also click **Logs** to inspect the full sync output.

    Congratulations—you have completed your first Airbyte sync.
  </Step>
</Steps>
